Windows 内核异常分发：从 Trap Frame 到用户态处理链

用户态看到的 VEH/SEH（向量化/结构化异常处理）只是异常分发的下游。真正的入口在内核：CPU 异常进入内核保存 Trap Frame（陷阱帧），KiDispatchException 构造异常记录，经过调试器 first chance（第一次机会），再通过 KiUserExceptionDispatcher 进入用户态处理链。
