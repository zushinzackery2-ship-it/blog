水面不是视频，也不是预渲染动画。它是一个运行在主线程 JavaScript 里的二维波动方程数值模拟：按固定时间步对高度场做邻域计算、衰减和乒乓交换，再把高度与梯度交给 Canvas 和 WebGL 渲染层。页面维护整页世界坐标下的高度场，固定 Canvas 只绘制当前视口；模拟与纹理编码也只处理视口附近的行。

为什么要手写波动模拟#

需要的效果是：鼠标划过时水面泛起涟漪，雨滴落下产生水花，偶尔刮一阵风让水面整体晃动。这种连续、物理感强的变形靠 CSS transition 或 sprite 帧动画做不出来——它需要一个持续迭代的高度场，并且任意位置都能注入扰动。

高度场模拟器不依赖物理引擎库：一个 Float32Array 存当前高度，另一个存上一个时间步的高度。每次模拟步完成后只交换两张 buffer 的引用，不复制数组。

降采样#

水面不需要逐像素精度。一个 1920×1080 的视口如果按像素建网格，高度场有两百多万个点，每次迭代都会产生大量邻域读取和浮点运算。

普通桌面配置中，每 5×5 个 CSS 像素对应高度场的一个格子。实际网格尺寸是 ceil(世界宽度 / 5) × ceil(世界高度 / 5)；仅看一个 1920×1080 视口，对应约 384×216 ≈ 83,000 个格子。长页面的高度场会继续向下扩展，但每次只推进视口附近的行，因此计算量不直接等于整张高度场的面积。

降采样因子是一个关键参数：值越大，网格越粗、计算越少，但水面细节也更模糊；值越小，网格越细，横纵两个方向的格子数都会增加。当前普通桌面基准是 fieldDown = 5、模拟间隔 14ms；窄屏或粗指针设备使用 fieldDown = 6、间隔 24ms。低并发或低内存桌面设备保持降采样因子 5，但把间隔放宽到 22ms。这些是运行时配置，不代表所有设备都能达到同一个帧率。

边界条件使用固定零值：每次迭代后把四条边写回 0。这不是严格的吸收边界，波到边缘仍会产生受固定边界影响的响应；只是全局阻尼会让返回的能量很快衰减。背景动画不需要额外实现更复杂的吸收层。

两层高度场#

维护两套独立的双缓冲：

  • 主波动层，damping = 0.988，用于涟漪、雨滴、点击等长时间持续的效果。
  • 运动层，damping = 0.92，用于鼠标拖动轨迹。

运动层衰减更快，这样鼠标划过时会留下一道短暂的”尾迹”，比涟漪消散快得多。两层在渲染时叠加，但在模拟时各跑各的迭代。

两层高度场的设计源于一个观察：鼠标拖动的视觉效果需要快速出现、快速消失，而涟漪需要缓慢衰减。单层高度场无法同时满足这两个时间尺度，因为阻尼是一个全局参数。分层就解开了这个耦合——每层有独立的阻尼系数，互不干扰。

不同事件注入不同的强度值和半径值：

事件强度半径目标层
鼠标点击较强中等主波动层
雨滴落水中等中等主波动层
鼠标移动弱小运动层
风阵极弱中等偏小主波动层

涟漪系统还会做一个延迟二次扰动：第一次注入之后 400-430ms 再注入一次较弱的脉冲，模拟水面回弹。这个时间窗口也是调出来的——太短回弹和主扰动重叠，太长回弹时水面已经恢复平静，看起来像两次独立的点击。

视口剔除#

博客页面可能很长，但用户只看到视口的一部分。系统仍按页面世界高度建立波场，使点击、雨滴和滚动共享同一套世界坐标；固定在屏幕上的 Canvas 只保留视口尺寸。模拟时只迭代视口附近的行：

视口上下各多算约 45% 的高度作为缓冲。如果文章有 5000 像素高但视口只有 900 像素，每个模拟步实际推进的纵向范围约为 900 × 1.9 ≈ 1710 像素，而不是全部 5000 像素。WebGL 高度场纹理也只编码视口上下带少量边距的切片，不上传整页波场。

缓冲区大小也是一个权衡点：太小滚动时波纹在边缘突然截断，太大失去剔除意义。45% 是实测下来滚动视觉连贯性最好的值。

风场#

初始化后约 2-3 秒会出现第一阵风；此后按 4-9 秒的随机间隔触发一阵持续 0.8-1.8 秒的风。风是一组随机分布在视口附近区域内的小扰动：

风心位置本身也随时间做正弦漂移，让风看起来不像一个固定点在反复抖。每阵风注入的一组脉冲强度很低，视觉上是水面局部微微起伏。

风参数的设计目标是能被感知，但不形成明显节拍。4-9 秒的随机间隔加上 0.8-1.8 秒的随机持续时间，避免风阵退化成固定周期动画。

模拟与渲染分离#

模拟系统本身只做计算，不直接画任何东西。它的输出是两组数据：

  1. 高度数组——每个格子的当前高度值（主波动层 + 运动层叠加）。
  2. 梯度采样——指定格子的 x/y 梯度和叠加高度。

这些数据可以被不同消费者读取：

  • 折射渲染：读取视口附近的高度场切片，编码成纹理上传到 GPU，在 shader 里做纹理坐标偏移。
  • 水面高光：读梯度和高度，在壁纸区域画短线段表示水面反光。
  • 星点与环境层折射：读取局部梯度，偏移星点、焦散和极光等背景元素。

这种”模拟和渲染分离”的结构让加新效果时不用碰模拟代码——只需要读高度场就行。

参数调节的原则#

参数调大效果调小效果
降采样因子网格更粗、更快但更糊网格更细、更慢但更精细
主阻尼波纹持续更久波纹消散更快
运动层阻尼鼠标尾迹更长尾迹更短
扰动强度涟漪/尾迹更大涟漪/尾迹更小
扰动半径涟漪扩散范围更大涟漪更集中
阵风密度风阵更密风阵更稀疏
阵风强度风浪更明显风浪更轻微
视口缓冲区视口外缓冲更大、更安全缓冲更小、更省

所有参数集中在一个配置对象里，运行时再根据视口、指针类型、设备并发数和内存信息应用配置档位。水面模拟没有跨设备通用的单一参数组：调整降采样、时间步或阻尼时，必须同时观察波速、细节和滚动帧时间，不能只看静止页面上的平均帧率。
