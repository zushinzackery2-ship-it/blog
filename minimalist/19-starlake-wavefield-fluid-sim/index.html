水面不是视频也不是预渲染动画。它是一个二维波动方程的数值模拟：每帧对一张高度场做邻居平均、衰减、乒乓交换，再把高度场的梯度输出给渲染层。整个模拟跑在主线程 JavaScript 里，靠降采样和视口剔除把开销压到可接受的范围。

为什么要手写波动模拟#

需要的效果是：鼠标划过时水面泛起涟漪，雨滴落下产生水花，偶尔刮一阵风让水面整体晃动。这种连续、物理感强的变形靠 CSS transition 或 sprite 帧动画做不出来——它需要一个真正的高度场在每帧迭代，并且任意位置都能注入扰动。

高度场模拟器不依赖任何物理引擎库，全部手写：一个 Float32Array 存当前高度，另一个存上一帧高度，每帧做一次波动方程迭代，然后把两张 buffer 对调。

降采样#

水面不需要逐像素精度。一个 1920×1080 的 Canvas 如果按像素建网格，高度场有两百多万个点，每帧迭代一次就是四百万次加法。

做法是降采样。每 5×5 像素对应高度场的一个格子。实际网格尺寸是 ceil(宽度 / 5) × ceil(高度 / 5)，1920×1080 的 Canvas 对应大约 384×216 ≈ 83,000 个格子。这个量级每帧迭代是可以接受的。

降采样因子是一个关键参数：值越大网格越粗、性能越好但水面细节越模糊；值越小网格越精细，但计算量平方级增长。5 是一个经验平衡点，在多数设备上能稳定 60 fps。

damping 设为 0.988。如果设成 1.0，波纹永远不会消散；低于 0.95 波纹几乎刚出现就消失。0.988 大概让一个涟漪在 100 多帧后衰减到不可见，视觉上是几秒钟。这个值对视觉体验极其敏感——差 0.005 就能让水面从”平静”变成”晃得头晕”。

边界条件用最简单的固定边界——四条边高度强制归零。波传到边缘会被完全吸收，不会弹回来。如果想要反射，可以把边界值设成邻居的值而不是零，但对背景动画来说吸收边界更自然。

两层高度场#

维护两套独立的双缓冲：

  • 主波动层，damping = 0.988，用于涟漪、雨滴、点击等长时间持续的效果。
  • 运动层，damping = 0.92，用于鼠标拖动轨迹。

运动层衰减更快，这样鼠标划过时会留下一道短暂的”尾迹”，比涟漪消散快得多。两层在渲染时叠加，但在模拟时各跑各的迭代。

两层高度场的设计源于一个观察：鼠标拖动的视觉效果需要快速出现、快速消失，而涟漪需要缓慢衰减。单层高度场无法同时满足这两个时间尺度，因为阻尼是一个全局参数。分层就解开了这个耦合——每层有独立的阻尼系数，互不干扰。

不同事件注入不同的强度值和半径值：

事件强度半径目标层
鼠标点击较强中等主波动层
雨滴落水中等中等主波动层
鼠标移动弱小运动层
风阵极弱中等偏小主波动层

涟漪系统还会做一个延迟二次扰动：第一次注入之后 400-430ms 再注入一次较弱的脉冲，模拟水面回弹。这个时间窗口也是调出来的——太短回弹和主扰动重叠，太长回弹时水面已经恢复平静，看起来像两次独立的点击。

缓冲区大小也是一个权衡点：太小滚动时波纹在边缘突然截断，太大失去剔除意义。45% 是实测下来滚动视觉连贯性最好的值。

风场#

在随机间隔（8-18 秒）触发一阵持续 0.8-1.8 秒的风。风是一组随机分布在某个区域内的小扰动：

风心位置本身也随时间做正弦漂移，让风看起来不像一个固定点在反复抖。每阵风注入的一组脉冲强度很低，视觉上是水面局部微微起伏。

风参数的设计目标是”能被感知但不会注意到规律”。8-18 秒的随机间隔加上 0.8-1.8 秒的随机持续时间，确保风阵出现的节奏不重复。如果固定间隔，用户很快就会发现”每 12 秒刮一次风”，变成了一个可预测的动画循环，失去了自然感。

能量检测#

需要一种方法判断某个矩形区域内的水面是否”安静”。按步长跳格采样，检查高度绝对值和梯度是否超过一个很小的阈值（如 0.012）：

如果高度和梯度都低于阈值，认为该区域水面平静。渲染层用这个判断跳过安静区域的绘制——如果水面完全平静，可以跳过折射计算以节省性能。

模拟与渲染分离#

模拟系统本身只做计算，不直接画任何东西。它的输出是两组数据：

  1. 高度数组——每个格子的当前高度值（主波动层 + 运动层叠加）。
  2. 梯度采样——指定格子的 x/y 梯度和叠加高度。

这些数据可以被不同消费者读取：

  • 折射渲染：读整个高度场做成纹理上传到 GPU，在 shader 里做纹理坐标偏移。
  • 水面高光：读梯度和高度，在壁纸区域画短线段表示水面反光。
  • 元素漂动：读梯度偏移其他 UI 元素位置，让它们随水波漂动。

这种”模拟和渲染分离”的结构让加新效果时不用碰模拟代码——只需要读高度场就行。

参数调节的原则#

参数调大效果调小效果
降采样因子网格更粗、更快但更糊网格更细、更慢但更精细
主阻尼波纹持续更久波纹消散更快
运动层阻尼鼠标尾迹更长尾迹更短
扰动强度涟漪/尾迹更大涟漪/尾迹更小
扰动半径涟漪扩散范围更大涟漪更集中
阵风密度风阵更密风阵更稀疏
阵风强度风浪更明显风浪更轻微
视口缓冲区视口外缓冲更大、更安全缓冲更小、更省

所有参数集中在一个配置对象里，改一个数字就能看到效果变化，不需要碰模拟逻辑本身。水面模拟没有”标准答案”，参数调优完全依赖设备性能和视觉偏好——低端设备可以把降采样因子调到 6，喜欢偏安静水面的可以把主阻尼降到 0.975。
