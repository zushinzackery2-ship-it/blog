字符画首先要知道“哪些像素属于主体”。如果主体概率来自神经网络，效果就取决于模型文件、运行时和输入分布；要一条完全本地、可解释、不携带模型的路径，就得从图像本身构造主体场。

可行的做法是一条有限、可诊断的数学管线：

这条路线不试图复刻语义分割模型。它回答的是更窄的问题：哪些区域与边框背景保持关系，哪些区域在局部或多尺度上偏离背景，并且这种偏离在从边框向内部传播时是否能维持。

实现的关键判断有三个：

  • 细节对比和背景连通是两种不同证据，只用一种必然在某类输入上翻车。
  • 主体占满画面时，频率调谐会把主体误当成背景，权重必须随填充程度切换。
  • 迭代次数、边框宽度、颜色距离温度和填充权重都是算法合同，不是可以随手调的超参：改动它们会改变主体极性与背景传播距离，必须同步更新测试。

下面的常数、公式和测试取自一个字符画管线的纯数学主体分支。引用它是为了让每条判断都有可复现的落点，管线本身不依赖字符画这个用途。

先把图像压到固定分析尺度#

原图可以很大，但主体场不需要在任意尺寸上反复运行昂贵的颜色距离和邻域扩散。analysis_hw 把最长边限制在 ANALYSIS_CAP = 192，短边按比例缩放，最低保持 8 像素。

分析尺寸与最终输出尺寸分开。主体概率在小图上建立，再用线性插值回到原图尺寸；字符网格阶段会重新采样概率。这样主体场的计算成本不会随源图像素数无限增长，且相同输入比例下更容易保持稳定。

所有颜色关系在 Lab 空间计算。RGB 欧氏距离会把亮度和色相混在同一坐标尺度；Lab 的 (L)、(a)、(b) 分量让背景色距离、局部对比和温度变化更容易解释。

FT 与 MIP 提供两种对比证据#

Frequency-tuned（FT）项先求全图 Lab 均值，对图像做 sigma=1 的高斯模糊，再计算模糊图与全图均值的颜色距离：

SFT(p)=∥Iblur(p)−μLab∥S_{\mathrm{FT}}(p) = \left\| I_{\mathrm{blur}}(p)-\mu_{\mathrm{Lab}} \right\|SFT​(p)=∥Iblur​(p)−μLab​∥

实现中的 frequency_tuned 最后归一化到 [0, 1]。它擅长突出相对于全局颜色中心的局部变化，但有一个明确缺陷：如果主体填满画面且颜色均匀，主体可能接近全图均值，边框反而因混合或压缩伪影变得更显著。

MIP center-surround 项把 Lab 图按 MIP_DIV = 8 缩到粗尺度，再放回原尺寸，与原图做距离：

它提供比 FT 更粗的中心-外围差异，能把大块主体与背景的关系保留下来。两者先各自归一化，再等权合成：

等权的作用是让细节证据和大尺度证据各自保持可观测、可单独替换。失败时分别查看 ft 和 mip 就能定位是哪一项失效，无须从一张合成后的 mask 里反推。

背景种子来自稳健边框统计#

主体场不从图像中心猜背景，而从边框建立背景关系。边框宽度：

先收集上下左右 frame 的 Lab 像素，计算每个像素的 chroma：

C=a2+b2C = \sqrt{a^2 + b^2}C=a2+b2​

丢掉高彩度边框像素后，取保留样本的中位 Lab 作为 bg_lab。默认保留 chroma 不超过第 55 百分位的样本；保留数量太少时才放宽到第 80 百分位。

随后用颜色距离把每个像素映射为背景相似度：

A(p)=exp⁡(−ΔE(p,bg)τ),τ=10A(p)=\exp\left(-\frac{\Delta E(p,bg)}{\tau}\right), \quad \tau=10A(p)=exp(−τΔE(p,bg)​),τ=10

seed 只在边框 frame 上写入 A(p)，内部像素保持 0；alike 则保留全图对背景色的相似度。边框因此成为传播起点，而“离背景色近”本身只作为传播时的通行条件，不直接给出背景判定。

为什么要丢弃高彩度边框？字符画输入可能带装饰边框、彩色 UI 或压缩边缘。如果直接平均，少量高彩度像素就能把背景色推离主体周围的真实背景。中位数和截尾策略牺牲少量边框细节，换取种子稳定性。

Jacobi 扩散建立背景连通关系#

边框种子需要向图像内部传播，但传播不能跨越明显颜色边界。jacobi_background 每轮收集 8 邻域：

颜色相近的邻居让背景隶属度继续传播；颜色差异大的邻居通过 gate 衰减传播。使用 max 而不是平均，保留了从任一可达背景路径进入的最大关系值；每轮重新把 seed 合入，保证边框不会被内部数值覆盖。

迭代固定为两级：

先在分析分辨率上做 8 轮粗扩散；如果尺寸允许，再放大一档做 2 轮细化，最后回到原尺寸。传播值只受 Lab 相似度和固定轮数约束，过程中不携带坐标、也不累积距离（与 JFA 的具体差别见文末）。

因此不能把这段算法改写成“一直迭代直到收敛”。更多轮数会改变背景穿越边界的距离，可能把相似色主体吸回背景；更少轮数则会让主体内部残留过多背景关系。迭代数是可验收的风格与计算合同。

主体占满画面时必须切换证据权重#

如果一张立绘几乎填满画面，中心半幅的 Lab 均值会接近全图均值。实现用它定义填充程度：

fill=11+ΔE(μcenter,μglobal)/18\mathrm{fill} =\frac{1}{1+\Delta E(\mu_{\mathrm{center}},\mu_{\mathrm{global}})/18}fill=1+ΔE(μcenter​,μglobal​)/181​

fill 的职责止于调整两种证据的权重：它衡量中心与全局的颜色统计差异，不判断画面里是否真的存在主体。

主体来源应当是可替换的 adapter#

compute_subject_probability 把主体来源抽象为 adapter：

纯数学分支默认 subject_mode="relation"，神经分割分支默认 semantic，界面上仍可切换三者做对照。把主体来源做成 adapter 的收益就在这里：换主体场不改变下游的区域编织、结构字形和渲染协议，只替换主体概率这一个输入。

职责边界由此固定：这条管线只生成主体场，字符选择与区域颜色、字形连续性都由后续的区域编织承担，两者共享同一条下游管线。

主体场进入局部预览时，半块模式先把每格上下两个采样区域算出颜色，再用主体概率与背景颜色混合：

因此 relation 的边缘会直接影响字符画主体与背景的过渡，但不会改变网格行列数或 glyph atlas。

计算边界和实现约束#

这条管线是 CPU NumPy/OpenCV 路径，采用固定分析上限与固定迭代，不要求 ONNX Runtime 或网络服务。它服务于本地、可审计、不携带模型的场景；需要通用语义分割时走神经分割分支。

它对以下输入更依赖：

  • 背景大致能从边框采样；
  • 主体与背景在 Lab 中存在可传播的颜色差异；
  • 边框不是大面积彩色装饰；
  • 主体关系可由颜色和空间连通近似。

透明 PNG 有 alpha 时，adapter 会优先直通 alpha；这条管线主要服务于没有可靠 alpha、又选择纯数学主体模式的输入。复杂遮挡、背景与主体同色、主体触碰画框这三类输入落在假设之外，应同时查看语义分割或 alpha 对照再下判断。

固定 192 的分析上限也意味着极细小目标可能在缩放时消失；提高上限会增加计算并改变细节关系，不应悄悄修改。任何参数变化都应同步 PASS manifest 与对应测试。

它与 JFA、神经分割的边界#

这类主体场常被叫成“距离场”或“无网络 JFA”，两个名字都不成立。

它不是 JFA，因为：

  • 没有传播最近种子的坐标；
  • 没有按 (1,2,4,\ldots) 跳跃的全局邻域；
  • 没有输出欧氏距离；
  • 每轮只收集固定 8 邻域，并用 Lab 差异衰减。

它也不是神经分割，因为：

  • 没有学习参数或模型权重；
  • 不输出语义类别；
  • 不理解“人”“动物”“物体”等类别；
  • 只根据输入图像的边框关系、颜色对比和空间传播构造概率。

准确的名称是“边框关系驱动的主体概率场”。它的优点是公式、轮数和中间图都可审计；代价是泛化范围由输入假设决定。

验收矩阵#

当前 unit 测试固定六类性质：

  1. 中心彩色 blob 的主体场高于 frame；
  2. 填充人像中 FT 可能反相，但 relation 不反相；
  3. Jacobi 第 8 轮的背景关系不低于第 1 轮；
  4. relation adapter 正确接入 saliency；
  5. public spec 暴露 relation 选项；
  6. 半块预览使用主体场后，边框颜色比未加权版本更接近背景。

这些测试锁定的是实现合同：有限迭代、主体极性、adapter 接线和输出形状不被后续重构破坏。效果层面的比较交给视觉验收。

视觉验收脚本会把同一输入的 semantic、relation 和结构输出并排生成。差异板显示主体场改变了哪些区域，优劣仍由人按输入类型判断。

结论#

这条管线可迁移的部分不是某个常数，而是三条结构性判断。

第一，单一证据一定有对偶失败。FT 在主体占满时把极性翻过来，边框连通在主体触碰画框时失效；两者叠加也消不掉失败，只是把失败推到更窄的输入集。所以权重要由一个可观测的量（填充程度）来调，而不是固定配比。

第二，迭代轮数在这里是风格与成本合同，不是可以“调到收敛”的超参。多迭代会让背景穿过颜色边界把相似色主体吸回去，少迭代会在主体内部留下背景残余。写成 while not converged 的那一刻，输出就不再可验收。

第三，中间图不是调试残留，是这套方法的验收接口。阈值只能改变输出强度，ft / mip / seed / walk 四张图才能区分“背景估计错了”“传播过远”和“极性反了”——这三种失败在最终 mask 上长得一模一样。

代价也明确：泛化范围由输入假设决定，而不是由训练数据决定。背景采不到边框、主体与背景在 Lab 中无可传播差异、边框是大面积彩色装饰，这三类输入落在模型之外，此时应当退回语义分割或 alpha 对照，而不是继续调参。
