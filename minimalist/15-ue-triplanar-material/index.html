同一张岩石纹理铺到几块尺寸不同的模型上，纹理密度往往很难一致。重新整理 UV 可以解决，但在地形、岩壁和程序化几何上，直接按空间位置投影更方便：一米长的纹理，在不同网格上仍然覆盖一米。

三面映射沿三个轴投影纹理，再按表面朝向混合结果。它减少了对展开 UV 的依赖，也把问题转移到了另一处：位置和法线采用什么空间，三个投影怎样交接，法线贴图的方向又如何统一。材质节点只是这些关系的表达。

Size 表示一轮平铺覆盖的空间尺寸。投影到 X 轴方向时，留下 Y、Z 两个分量；另外两个方向同理。这也解释了三面映射的基本成本：同一张纹理通常需要采样三次。

位置所在的空间会直接改变观感。世界空间投影让相邻模型容易共享纹理尺度，但模型移动时，表面会穿过固定在世界中的纹理。局部空间投影会随模型一起移动和旋转，更适合需要移动的物体；对象缩放后，纹理在世界中的尺寸也可能跟着变化。

在 UE 中，ObjectPositionWS 给出的是对象包围盒中心的世界位置，它在同一对象上近似为常量，不能替代逐像素的局部位置。需要局部投影时，应使用对应的局部位置表达式，或把表面世界位置变换到所需空间。减去对象中心只消除了平移，并没有消除旋转和缩放。

非均匀缩放会让问题更明显。若位置按一套变换计算，而法线仍留在另一套空间，纹理方向与混合权重就会错开。法线也不能机械套用位置的变换规则；它需要正确的法线变换与归一化。

因此，世界空间和局部空间的选择，实际上是在决定纹理固定于场景还是附着于对象。这个选择应在调整平铺参数之前完成。

朝向权重让三个投影接起来#

只按某个轴投影时，侧面的纹理会被拉长。三面映射用表面法线判断哪个投影更合适：朝向 X 的面多用 YZ 投影，朝向 Z 的面多用 XY 投影。

归一化很关键。三个权重之和为一时，相同颜色经过混合仍然保持原值，否则亮度会随表面朝向变化。分母中的小量只用于避免退化输入产生除零，正常单位法线本身至少有一个非零分量。

权重通常来自尚未叠加这张法线贴图的表面法线。若用最终扰动后的法线反过来决定同一次采样的权重，就会把采样与着色方向耦合起来，让结果更难控制。

颜色和遮罩可以共享投影，采样语义各不相同#

Base Color、粗糙度和遮罩都能使用相同的坐标与权重，但它们代表的数值不同。

颜色纹理通常以 sRGB 存储，采样后在线性空间混合。若采样器已经完成 sRGB 解码，材质里再做一次转换就会压暗颜色。粗糙度、金属度、遮罩和高度等数据纹理则通常直接按线性数值解释。

把 AO、Roughness、Metallic 打包到一张 ORM 纹理，可以共享三次采样。不过 RGB 分别代表什么仍由资源约定决定，通道名称本身不能替代约定。

这种区分也适合用来组织材质函数：坐标和权重只计算一次，颜色与数据纹理各自采样，再把结果组成材质属性。函数的边界与数据含义一致，修改采样方式时就不容易顺带改变颜色空间。

法线贴图需要先统一方向#

颜色样本是颜色，法线样本是一个局部基底中的方向。来自 XY、XZ、YZ 三个投影的法线，即使 RGB 完全相同，也未必指向同一个空间方向。

投影轴的符号也不能忽略。仅仅交换 XYZ 分量，可能让背面的凹凸方向翻转。一个实用的检查是把法线贴图换成平坦法线：无论物体朝向如何，结果都应恢复到预期的表面法线。做不到这一点，就说明重定向或与几何法线的组合仍有问题。

如果材质输出期待切线空间法线，而混合结果处在世界空间，还需要一次明确的变换。把三个方向加在一起后做 normalize，只能恢复长度，修复不了空间错误。

材质层的混合是另一个问题#

三面映射解决一层材质怎样落到表面。岩石上再覆盖青苔、积雪和湿润层，则需要决定层之间的关系。

这两种模型看起来都在做插值，交换通道后却会有不同结果。问题出在遮罩的含义，继续增加混合节点不会自动解决。

UE 的 Material Attributes 便于把一层的属性组织在一起，但打包属性不会替代混合设计。尤其是法线，仍要确认所采用的混合方式是否符合预期，不能把属性混合一概理解为完整的物理分层。

成本随材质层数一起增长#

三面映射的成本很容易被节点图隐藏。一层材质若分别采样 Base Color、Normal 和 ORM，基础开销通常就是九次纹理采样；再叠加多层，成本继续累积。坐标复用能减少重复运算，却不会自动消除这些纹理读取。

因此，它更适合用在确实受益于空间投影的部分。大面积岩壁需要稳定的纹理尺度，三面映射很有价值；已经有合适 UV 的细节层，则可以继续使用原有采样方式。具体取舍还要结合材质编译结果、实际屏幕覆盖率和目标硬件测量。

三面映射的可控性，来自位置、朝向、采样与层关系各自清楚。沿着这条数据流回查，纹理滑动可以追到空间选择，过渡重影可以追到权重，凹凸翻面可以追到法线基底。材质复杂之后，这些因果关系比节点数量更有用。
