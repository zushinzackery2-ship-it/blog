卡片箔面材质：让颜色随表面与视角变化

给卡图叠一层彩虹纹理，很快就能得到鲜艳的效果。但转动卡片时，如果颜色只是平移，整张图又同时发亮，观感就更接近彩色遮罩，缺少箔面随角度变化的质感。

这个差异来自几种关系：哪些位置允许出现箔面，表面朝向怎样影响反光，连续图案与细碎闪点怎样分工。把这些关系建立起来后，强度和颜色参数才有稳定的含义。

在一套 WebGL2 卡片材质中，我更倾向于用同一个着色器解释这些关系，再用配置描述不同卡片的差异。这样调整的对象是表面特征，各种卡片也能共享同一套修正。

箔面区域与反光强度分别控制#

卡片上的图像、名称、边框和符号未必使用相同工艺。一张遮罩图可以标记这些区域，材质配置再决定每个区域参与箔面、浮雕或碎闪的程度。

遮罩回答的是位置，粗糙度和高光参数回答的是响应。若把它们混成一个全局强度，调亮名称时可能顺带照亮整张卡，结果很难解释。

浮雕也应有独立的数据含义。高度图的局部差分可以改变表面法线，进而影响反光；边缘高光则是在现有表面上增加某种响应。共用一个参数会让“更亮”和“更凸”被迫一起变化。

颜色空间属于同一层约定。印刷卡图通常以 sRGB 解释，遮罩与高度通常作为线性数据。虹彩查找表则取决于它保存的是显示颜色还是数值数据，采样路径需要与资源定义一致。把所有纹理统一标成 sRGB，可能直接改变遮罩权重和高度。

角度关系让高光附着在表面上#

建立了区域之后，还需要表面法线、光线与视线。它们决定漫反射、宽高光、窄高光以及掠射角附近的变化。

粗糙度可以调节高光分布，局部浮雕法线可以让同一块区域内部产生起伏。这样卡片转动时，反光变化与表面方向相关，眼睛才容易把它理解为一种材质。

虹彩也可以沿这个关系生成。一种便于控制的做法是将观察角度、反射方向和少量动态位移组合为相位，再从一维颜色表采样：

这是用于风格化表现的近似模型。它能建立稳定的角度响应，但一张彩虹 LUT 并不等于完整的薄膜干涉计算，也不自动满足物理上的能量守恒。

因此，材质的判断重点仍是变化是否连贯：静止时表面应稳定，转动时颜色与高光应沿角度平滑变化，未覆盖箔面的区域应保留印刷图像的可读性。

大图案与小闪点承担不同尺度#

斜线、交叉纹和晶格提供连续的表面结构。它们决定从中等距离看去，箔面有怎样的方向和节奏。

稀疏闪点则负责短暂、局部的亮度变化。可以在格子中生成固定位置与局部方向，再根据视角和时间计算闪光。更大的晶片还可以使用局部微法线，使它们只在特定方向出现明显反射。

如果所有格子都常亮，碎闪就会变成一层大色块；如果大图案过强，又会遮住卡图。两者分别控制尺度、覆盖和强度，比单独增加噪声层更容易调整。

随机种子在这里很重要。它决定闪点和碎片的空间分布，强度决定这些点多亮。若把二者绑定到同一个参数，拖动亮度滑块时整片闪点会重新排布，人就无法判断自己到底改变了什么。

同样的分离也有助于比较：固定种子、相机和时间，再改粗糙度，画面差异才主要来自粗糙度。

数据配置保留差异，着色器保留共同规则#

不同卡片可以有不同的遮罩权重、浮雕强度、虹彩范围和碎闪密度。这些差异适合进入配置，而光照、采样和组合顺序由共用着色器解释。

这样修正一次虹彩采样，所有使用它的配置都会接受修正。若每种卡片复制一份着色器，几轮调试后就容易出现公式分叉，同名参数也逐渐失去共同含义。

配置中的“普通”“银灰”“晶格”等名称，只是当前视觉设计的预设。它们可以对应某套卡片的稀有度，也可以用于完全不同的分类，并不构成现实印刷工艺的通用标准。

共用着色器也不意味着所有效果永远执行同样多的工作。关闭某层能否减少实际开销，取决于编译、分支和资源访问方式，需要检查最终执行情况。

中间视图比继续调总强度更有用#

最终画面把所有层混在一起。遇到卡名区域翻转、边框过曝或大块彩色噪声时，直接调总强度通常会连带影响本来正确的部分。

暂时只显示某一层，可以把问题缩小：

观察内容能区分的问题
加权后的箔面遮罩区域、UV 与通道解释是否一致
原始图案与碎片分布尺度、种子与覆盖是否符合预期
浮雕法线高度方向和强度是否正确
虹彩与高光角度响应及颜色采样是否连贯

这些视图最好使用最终材质中的同一份计算结果。另写一套“调试算法”，可能恰好绕过真实错误。

这种观察方式也让移植更容易。换成另一种着色语言时，可以先对齐遮罩与图案，再对齐法线和角度响应，最后比较完整画面。每次差异都有一个具体层级。

性能数字需要对应实际工作#

材质开销与卡片覆盖的像素数量、设备像素比、采样次数、分支和多卡叠加有关。程序化密度变低，视觉上虽然更稀疏，计算量却未必同比减少：若每个像素仍执行同样的循环和查找，成本可能变化很小。

浏览器中的 CPU 帧耗时也不能直接代表这段着色器的 GPU 成本。WebGL2 的 timer query 可以测量查询区间内的 GPU 时间，但这个范围只覆盖被包围的命令，未必包括浏览器整帧合成与呈现。

结果需要异步读取；出现 disjoint 状态时，相应样本不可用于比较。扩展不可用时，应保留“未取得 GPU 时间”的状态，CPU 数据可以单独展示，但两者不能互相替代。

比较材质配置时，固定分辨率、卡片覆盖率、质量参数、设备和驱动，再说明测量包围了哪些命令，数字才有意义。脱离这些条件的一两个毫秒值，很难指导另一个人的实现。

箔面效果的完成度来自这些可解释的关系：区域确定位置，表面方向决定响应，不同尺度建立细节，数据配置组织变化。它们稳定之后，调色与调亮度才成为可控的艺术选择。
